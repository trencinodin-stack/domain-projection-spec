# ADR-008: Preservation of Phase 7 Immutability via Additive Domain Projection

## Status
Accepted (Canonical)

## Context
Phase 7 established the formal reference monitor baseline and epistemic protocol invariants (I1–I3) for Admissibility Science, anchored on `admissibilityscience.com`.

With the formalization of the Domain Projection Paradigm (ARC-SPEC-2026-DPP-01), concrete verification harnesses, Plonkish ingress circuits, and cyber-physical observation boundaries have been specified. 

We require an architectural decision regarding the deployment topology and repository governance of this new specification relative to the existing Phase 7 corpus.

## Decision
1. **Strict Non-Supersession:** 
   - The Phase 7 canonical field root repository (`trencinodin-stack/admissibilityscience.com`) remains frozen and sealed at release tag `v1.0.0`.
   - Phase 8 does not modify, refactor, or supersede Phase 7 theorems; it acts strictly as an additive domain projection mapping.
2. **Provenance & Subdomain Isolation:**
   - The Phase 8 specification and verification artifacts are isolated in an independent repository (`domain-projection-spec`).
   - Public routing is anchored to the dedicated subdomain `paradigm.admissibilityscience.com`.
3. **Operational Constraint:**
   - The deployment maintains the universal zero-operational-drag constraint ($C_{\text{ops}} = 0$). All hosting is static edge delivery via Cloudflare Pages with zero recurring compute maintenance.
4. **Toolchain Pinning:**
   - Mechanized proofs require Coq 8.18.0 with zero admitted lemmas.
   - Reference engine runtime requires freestanding Rust 1.75.0 (`#![no_std]`).

## Consequences
- **Positive:** Phase 7 immutability is preserved; citation links and Zenodo theoretical roots remain undisturbed.
- **Positive:** Auditors have an isolated, zero-dependency environment to check Plonkish gates and Coq proofs.
- **Negative:** Requires managing cross-domain metadata references rather than a single monolithic web tree.
