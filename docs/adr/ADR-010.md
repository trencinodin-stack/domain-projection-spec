### 1. Context & Motivation

ADR-008 established repository isolation and baseline non-supersession for Phase 8, while ADR-009 introduced the discrete Gronwall residual ($\gamma \in \mathbb{Q}$) evaluated over an earlier $\Delta t_{\max} \le 13.19\,\text{ms}$ timing budget.

With the ratification of the canonical capstone specification *The Mechanics of Admissibility* (`ARC-CAPSTONE-2026-SYNTH-01-REV19`, DOI `10.5281/zenodo.24093739`), two physical refinements were standardized across the ecosystem:
1. **Conserved Cyber-Physical Latency:** A unified 4-stage timing budget bounded by $T_{\text{total}} \le 16.50\,\text{ms}$ with discrete evaluation watchdog $\tau_{\text{eval}} \le 10.00\,\text{ms}$, replacing the isolated $13.19\,\text{ms}$ airlock estimation.
2. **Mechanical Deadband Latch Envelope ($d_{\text{latch}}$):** Accounting for physical brake pin insertion and holding displacement during low-velocity clamp transitions ($v \le \epsilon_v$), expanding $M_{\text{stop}}$ to the latched functional $M_{\text{stop}}^L$.

This ADR documents the formal alignment of `domain-projection-spec` with the REV19 capstone baseline while preserving ADR-008's isolation guarantees.

---

### 2. Decision

1. **Harmonized Latency Budget ($T_{\text{total}}$):**
   The continuous-to-discrete timing window in ADR-009 ($\Delta t_{\max} \le 13.19\,\text{ms}$) is updated to the conserved end-to-end cyber-physical budget:
   $$T_{\text{total}} = \tau_{\text{sense}} (1.50\,\text{ms}) + \tau_{\text{eval}} (10.00\,\text{ms}) + \tau_{\text{sync}} (1.20\,\text{ms}) + \tau_{\text{brake-engage}} (1.81\,\text{ms}) = 14.51\,\text{ms} \le 16.50\,\text{ms}$$
   Enforcing $1.99\,\text{ms}$ certified timing slack. Hardware NMI override clamp $\tau_{\text{override}} \le 11.99\,\text{ms}$ remains the hard physical fallback.

2. **Integration of Mechanical Latch Buffer ($M_{\text{stop}}^L$):**
   The double-integrator kinetic stopping functional is augmented with the deadband latch displacement $d_{\text{latch}}$:
   $$M_{\text{stop}}^L(v) = v T_{\text{total}} + \frac{1}{2} a_{\max} T_{\text{total}}^2 + \frac{(v + a_{\max} T_{\text{total}})^2}{2 a_{\text{brake}}} + d_{\text{latch}}$$
   where:
   $$d_{\text{latch}} = \frac{\epsilon_v^2}{2 a_{\text{brake}}} + \epsilon_v \tau_{\text{latch-lock}}$$

3. **Constructive Rational Witness Evaluation:**
   The offline Gronwall witness $\gamma$ continues to evaluate via fixed-point rational arithmetic ($\gamma \in \mathbb{Q}$) per ADR-009, scaled across the unified $T_{\text{total}}$ parameter envelope without runtime heap allocation ($M_{\text{alloc}} = 0$) or floating-point instructions.

4. **Admissibility Predicate Enforcement:**
   The runtime robust predicate enforced by the `#![no_std]` reference engine is:
   $$\mathcal{D}_{\text{robust}}(a) = \begin{cases} \text{PERMIT}, & \text{if } [h(\hat{x}(t)) - M_{\text{stop}}^L(\hat{x}(t)) \ge \gamma] \wedge [\tau_{\text{eval}} \le 10.00\,\text{ms}] \\ \text{DENY}, & \text{otherwise} \end{cases}$$

5. **Formal Verification Demarcation:**
   `domain-projection-spec` is designated as the downstream verification and realization harness. Pure mathematical proofs and boundary handoff theorems ($F_L \equiv B$) reside in `ARC-CAPSTONE-2026-SYNTH-01-REV19` and are not reopened by implementation-level test benches.
